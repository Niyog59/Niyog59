## Data Analytics

**Airline Route Profitability**

A project with Shaheer Ahmed exploring how profit varies across demand levels, seasons, route categories, and passenger loads in a simulated airline dataset.

The analysis uses R to clean the data, compare groups, and visualize the results. It distinguishes total profit from profit margin and discusses the limits of drawing conclusions from simulated data.

<sub>R · tidyverse · ggplot2 · R Markdown</sub><br>
<a href="https://github.com/Niyog59/Airline-Profitability">Explore project</a>

## SQL & Database Design

**Gym Management System**

A MySQL database for members, trainers, membership plans, classes, and enrollments. The project includes a relational model, an ER diagram, sample data, and SQL queries for everyday gym operations.

The schema uses foreign keys and validation rules to protect relationships and prevent invalid records.

<sub>SQL · MySQL · MySQL Workbench · draw.io</sub><br>
<a href="https://github.com/Niyog59/Gym-Management-Project-MySQL">Explore project</a>
